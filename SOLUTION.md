## 🧩 Key Approach: The 4-Pillar Adaptation Framework

### Pillar 1: Directional Glyph Disambiguation Engine
- **Mechanism**: Attaches subtle, high-contrast visual micro-anchors to symmetrical mirror letters ($b, d, p, q, m, w, n, u$).
- **Visual Cue Logic**:
  - `b`: Left ascender glow / directional stem dot (indicates left-to-right bowl orientation).
  - `d`: Right ascender color accent (indicates right-side stem orientation).
  - `p`: Lower descent cue (indicates downward left orientation).
  - `q`: Lower right-tail accent (indicates downward right orientation).
- **Result**: Neutralizes mirror invariance in the visual cortex, allowing instant character recognition without cognitive hesitation.

### Pillar 2: Dynamic Spatial De-Crowding & Reflow
- **Mechanism**: Calculates optimal letter-to-letter and line-to-line spatial ratios to prevent lateral visual crowding.
- **Features**:
  - Dynamic inter-character spacing (kerning multiplier).
  - Expanded inter-line height (1.8x–2.4x dynamic baseline shift).
  - Column constraint bounding (restricts line width to 50–65 characters per line to reduce horizontal saccadic amplitude).

### Pillar 3: Gestalt Visual Word Memory Highlighter
- **Mechanism**: Groups words into visually distinct structural units (syllabic blocks and morpho-syntactic roots) using subtle alternating visual gradients.
- **Result**: Stimulates whole-word visual gestalt recognition, allowing Dyseidetic readers to construct mental sight-word memories faster.

### Pillar 4: Motion & Fixation Stabilization
- **Mechanism**: Interactive reading line overlay (Optical Ruler) and peripheral dimming spotlight.
- **Features**:
  - Active line highlight mask follows mouse cursor or touchpad focus.
  - Peripheral line dimming blurs adjacent lines, preventing horizontal and vertical saccadic drift.
